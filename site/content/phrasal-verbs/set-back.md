## 📖 Köken ve Yapı

Set back, 'set' (koymak, yerleştirmek) ve 'back' (geri) kelimelerinin birleşmesiyle oluşur. Kelimenin kökeni, bir şeyi geriye doğru itmek veya ilerlemesini engellemek fikrine dayanır. 17. yüzyıldan itibaren mecazi olarak 'geciktirmek' anlamında kullanılmaktadır.

</div>

<div class="custom-card info-card">

## 💬 Örnek Cümleler

**1.** The bad weather set back the construction of the bridge by two weeks.

*Kötü hava koşulları köprünün inşaatını iki hafta geciktirdi.*

---

**2.** Losing that client really set back our plans for expansion.

*O müşteriyi kaybetmek, büyüme planlarımızı gerçekten sekteye uğrattı.*

</div>

<div class="custom-card error-card">

## ⚠️ Sık Yapılan Hatalar

❌ **Yanlış:** Yanlış: The bad weather set back the project by two weeks. (Bu doğru aslında; yaygın hata: set back'ın 'geri çekmek' anlamında kullanılması: 'He set back the chair.' → Doğrusu 'He set the chair back.')

✅ **Doğru:** The technical issues set the launch back by three months.

</div>

<div class="custom-card">

## 🔗 Eş ve Zıt Anlamlılar

🔄 **Benzer:** delay, postpone, hinder

↔️ **Zıt:** advance, hasten

</div>

<div class="custom-card">

## 💡 Kullanım Notu

Hem resmi hem günlük dilde kullanılır, ancak günlük konuşmada daha çok 'geciktirmek' anlamında yaygındır.
