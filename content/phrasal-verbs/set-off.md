## 📖 Köken ve Yapı

Set off, Eski İngilizce 'settan' (yerleştirmek) ve 'of' (ayrılma) kelimelerinin birleşmesiyle oluşmuştur. 16. yüzyıldan itibaren 'bir yolculuğa başlamak' anlamında kullanılmaktadır.

</div>

<div class="custom-card info-card">

## 💬 Örnek Cümleler

**1.** We set off for the airport at 5 a.m. to catch our flight.

*Uçuşumuzu yakalamak için sabah 5'te havaalanına doğru yola çıktık.*

---

**2.** The loud noise set off the car alarm.

*Yüksek ses, araba alarmını tetikledi.*

</div>

<div class="custom-card error-card">

## ⚠️ Sık Yapılan Hatalar

❌ **Yanlış:** Yanlış: 'I set off the trip.' Doğrusu: 'I set off on the trip.' (set off yolculuğa başlamak anlamında geçişsizdir, 'on' edatı eklenir.)

✅ **Doğru:** We set off at dawn to reach the village before dark.

</div>

## 🔗 Eş ve Zıt Anlamlılar

🔄 **Benzer:** set out, set forth, embark on

↔️ **Zıt:** arrive, return
